# 网页移动与触屏体验

本次改造保持现有 M3 Expressive 色彩、字体、形状与动效令牌，以及 Web / Electron 共用的数据和能力边界。网页按设备能力和可用空间选择展示方式，Electron 继续使用原有工作台。

## 信息与操作

- 手机以“总览 / 设备 / 设置”为三个一级入口。总览先回答设备是否在线，再列出离线设备和本浏览器的常用设备；没有自定义告警阈值或健康评分。
- 设备目录使用纵向列表，搜索直接显示，状态筛选与排序放在底部面板。常用设备仅影响本浏览器；中枢顺序在管理模式中调整并明确保存。删除仍表示删除登记，Agent 再次上报会重新出现。
- 详情分为“状态 / 趋势 / 硬件”。趋势中的分类继续使用完整设备面板定义，CPU、磁盘、网卡、流量日历、GPU、温度与风扇等仍可访问。详情的当前读数与图表数据保留各自真实时间；切换设备或范围不会借用另一台设备的遥测。
- 设置先显示分类再进入具体内容，使用原有设置页与平台能力。通用设置增加安装说明与本地缓存清除入口，外观设置可手动选择自动、触屏或桌面布局。

## 手机和平板

自动模式优先使用窗口宽度、触控与指针能力，UA 仅辅助区分横屏手机、iPad 的桌面 UA 和平板分屏。手机横屏保持底部导航；平板在 600px 起显示导航轨，840px 起可同时显示设备目录与详情。平板窄分屏退回单栏。

搜索、筛选、常用项、每台设备的详情分类和滚动位置由自适应分支外的 UI 状态保存。旋转与分栏切换共用同一个 WorkspaceProvider、轮询和适配器。

触屏控件的目标至少 48px。保留浏览器缩放，使用安全区、动态视口和 VisualViewport 处理系统栏与键盘。底部面板使用原生 dialog 的焦点约束和背景 inert 行为，并加入历史记录，使系统返回先关闭面板。页面返回保留原目录上下文。M3 动效仅用于导航、面板和操作反馈，刷新数据不重播页面动画；减少动态效果时取消这些动画。

图表横向查点与纵向滚动分离，保留捏合缩放；键盘也可用方向键、Home、End 查点。下拉刷新避开控件、图表与屏幕边缘，取消手势不会触发刷新。

## 离线与更新

公开应用壳和静态资源由 Service Worker 缓存；API、认证、socket 和 RSC 请求始终绕过 Cache Storage。生产构建在 CI 生成资源清单和源码修订标识，不依赖发行版本号变化。只有 HTTPS 或浏览器认可的安全上下文支持离线启动；开发服务器不注册 Worker。

设备快照通过 IndexedDB 存在单个当前会话作用域中，不存访问密钥、Cookie、本机 Agent 配置或更新地址。默认最多保存 8 个设备/范围视图、约 4MB 序列化数据，24 小时后不可用于离线恢复。新会话替换旧视图，显式退出和当前请求的 401/403 清空缓存，重置会通知其他打开的页面。较早的启动或重连请求不能用过期响应清空新会话或退回登录页。存储不可用时仍能在线查看。

断网后显示缓存保存时间，当前在线状态与需关注数量标为待确认；管理操作不可用。尚未缓存的设备历史、时间范围或日历周期显示无可用数据，不借用其他范围。启动时仅认证失败进入登录，网络失败先尝试缓存，否则显示重新连接。请求及响应体读取最多等待 12 秒；即使底层传输忽略取消，也会结束等待。已恢复的缓存直接提供目录与详情，不重复等待启动认证；刷新、前台恢复或网络恢复会重新验证连接，后台暂停轮询并关闭 socket。读取尚未结束时连续切换设备或指标范围，排队的读取使用用户最后选择的设备与范围。初次读取目录时显示加载状态，读取失败显示重试入口，不把未知状态显示为空目录。

新 Worker 只有在整个公开资源集合与应用壳修订标识匹配、缓存完成后才能进入等待状态。失败删除候选缓存并保留原可用版本。更新由用户点击；有顺序草稿或输入时提醒先保存。缓存仅保留当前和前一代，帮助已经打开的页面继续加载旧静态资源。版本切换、实际安装和系统返回体验仍需真机验收。

## 验证

- `pnpm test:ui-helpers`：手机横屏、iPad 桌面 UA、平板分屏、混合输入与用户选择。
- `pnpm test:web-pwa`：请求及响应体超时、忽略取消的传输、调用方取消、401 语义、只读与敏感字段剥离、设备/范围/日历隔离、会话切换、容量与过期，以及 Worker 原子安装和 API/RSC/socket 排除。
- `scripts/mobile-touch-regression.cjs`：手机 320/360/390/430/736px、平板 430/768/834/1024/1366px；搜索与返回、分层详情、常用设备、排序、只读缓存、重新连接、过期响应竞争、401/403 清空、减弱动效、放大文字、存储拒绝与空目录。
- CI 的 Web 视觉任务运行生产构建，并在 Chromium 和 WebKit 上通过真实触屏点击执行同一流程及 Worker 的离线重新打开。移动套件使用本地 HTTP 模拟中枢，API 经真实网络到达，避免 Worker 控制页面后浏览器请求拦截能力的差异。Chromium 使用浏览器断网仿真；WebKit 停止模拟中枢的监听并验证应用壳由 Worker 提供，未注册 Worker 的页面必须加载失败。后者验证服务不可达时的恢复，不代表真机断网；WebKit 自动化离线开关的限制见 [Playwright #42775](https://github.com/microsoft/playwright/issues/42775)。原桌面布局的既有视觉套件和 Electron 视觉套件继续运行。

浏览器模拟、WebKit 引擎测试和 CI 不能证明物理 iPhone、Android 手机或平板的主屏幕安装、软键盘、系统手势、长时间后台恢复。发布和部署前应在真实设备上完成这些验收；本改造不触发发行版本或部署。
