## 已采集的基线（2026-10-20）

测量版本为 NAS 当前生产版本对应的提交，**没有部署本任务代码**。
macos-dev 上以 `curl --compressed` 顺序采样未认证首页，每条路径 5 次：

## 阶段 2 行为

Web 会话初始化合并并发验证，首次视图复用刚通过的会话；手动刷新仍验证，数据 401/403 仍立即失效。
列表读取后先发布摘要；图表与日历各自完成即发布，更新查询不参与刷新等待。
离线缓存写入安排在后续任务，不等待 IndexedDB；图表补齐后可覆盖摘要缓存，保留常规写入节流。
每次发布及异步写入都检查请求和身份代次，旧选择、退出前响应不得恢复私有数据。
本阶段未改变公共壳策略或缓存启动顺序；缓存优先启动在 Web/PWA 和原生专项继续完成。
刷新 Promise 仍等待当前视图所需图表/日历，但摘要已经可见；弱网取消与调度在阶段 4 完成。

## 阶段 3 服务端读取

- `/api/instances` 保持现有轻量标量摘要契约，仅并发读注册表与实时状态，不查询历史表。
  历史独有设备在监听后后台恢复注册，失败 30 秒后串行重试，成功后不再周期扫描。
  历史恢复完成前可能短暂缺少历史独有设备；关闭设备不重开，现有注册设备不受历史库慢/不可用影响。
- 历史恢复查询先分别在分钟/小时表按设备求最大时间，再合并，保留分钟独有、小时独有和重复设备的语义。
  NAS 只读候选查询单次 422 ms，EXPLAIN 从约 34 万行降至约 26 行并使用 `Using index for group-by`。
  这不是已部署 API 的对比结果，不用于声称首屏改善比例。
- 日历查询覆盖完整可见网格（含相邻月日期），SQL 使用设备与半开时间范围，只投影时间与两个流量计数。
  继续保留一年读取期限、既有计数器重置语义及当前小时/分钟覆盖；不读取或解析硬件 JSON。
  本地存储与 MySQL 使用相同边界。没有更改图表的完整历史查询或流量总计算法。
- 增加小时表 `(device_id, recorded_at, traffic_rx_bytes, traffic_tx_bytes)` 覆盖索引，沿用启动时幂等 `ensureIndex`。
  本次没有在线执行 DDL。未来首次部署会建索引，需留出建索引的 IO/启动时间；回退代码不必删除该加性索引。
  没有覆盖索引时，只读投影候选单次仍耗时 5058 ms（481 行/约 43.6 KB），因此不能只凭响应字段变少宣称 SQL 已快。
- 独立 PR CI 使用 runner 本机 MySQL 8.4，连接级临时表比较旧/新发现结果、日历各模式和大 JSON 投影排除；不接触生产数据库。
- 点数预算与阶段 4 同批实现：当前客户端依赖原始采样间隔识别缺口，直接稀疏采样会把采样误认为断线，
  也可能丢峰值或改变流量累计。必须先补齐可选请求契约和渲染语义，默认旧客户端继续完整读取。

## 阶段 4 弱网策略与读取预算

- 通用设置提供自动/标准/省流，偏好只存本机；默认自动。自动使用浏览器的 saveData、低速连接提示或
  摘要请求的平滑耗时（≥1500 ms）判断受限，不根据域名猜测线路，也不把含 Hub 工作时间的请求耗时标成 RTT。
  标准模式不发点数目标，是需要完整序列时的回退；省流与受限自动模式的自动刷新/推送补图最短间隔 30 秒。
  原生传输尚未接入自适应读取，当前共享桌面设置仅把省流轮询下限设为 30 秒；Android 在阶段 6 实现。
- Web 可选图表、日历、更新读取最多 2 路，受限时 1 路；等待队列上限 32。
  认证与摘要保留独立路径，不受慢日历/更新占位影响；这不是整个浏览器总请求数限制。
  队列按同资源键与同取消生命周期合并，身份不同不共享结果。更新优先级最低，且不参与刷新完成等待。
- 切换设备/范围/策略、离线、隐藏、退出和卸载订阅取消旧读取及等待队列；即使底层传输不响应取消，调用方仍能结束。
  身份与请求代次继续隔离迟到结果；补齐旧推送图表 401 不得清除新身份的保护。
  GET 可以被下一轮轮询重新读取，任何管理写入都不自动重放。
- 摘要失败和图表失败分别记录退避，自动间隔指数增加到最多 120 秒；成功恢复对应计数归零。
  手动刷新和 online 恢复立即执行，不等待自动退避；图表失败不丢掉成功的实时摘要。
- `/metrics`、`/overview/metrics` 增加可选 `pointBudget=16..2000`（整数）及可选 `sampling` 元数据；
  未传参数的旧客户端响应不变。受限 Web 请求目标为 120 点，旧 Hub 忽略未知参数时仍能返回完整数据。
- 抽样保留原时间戳、首尾和每桶极值。嵌套硬件与标量必须具有相同时间轴，使用各序列保留时间的并集，
  使客户端实例求和/平均在保留时刻仍然正确。目标不是硬上限；不同时间轴、真实缺口、非法数据、
  抽样后可能产生假缺口或并集已覆盖原数据时返回完整数据。流量累计、成对网络速率始终完整。
  这优先保证正确性，不承诺所有硬件响应都缩到 120 点；也不降低数据库完整读取成本。
  半屏统计说明抽样均值并非完整均值；组合曲线的完整窗口极值也不能由单个组件的抽样极值推导。
- 自动测试验证取消不等 12 秒超时、并发/优先级/去重、身份隔离、失败退避/恢复、点数参数认证/边界、
  峰谷/首尾/缺口/累计语义及嵌套伙伴的对齐。均为夹具验证，未部署且不代表真实公网或原生设备验收。

## 阶段 5 Web/PWA 启动

- 启动并行读本机快照与验证会话：缓存命中立即进入明确标记的只读视图，不等待 12 秒网络超时；
  401/403 覆盖缓存并清空，旧启动/迟到存储结果不能覆盖新会话。会话成功后缓存视图立即触发实时摘要读取，
  不再额外等一轮轮询；无缓存时仍需有效会话才能进入实时控制台。
  IndexedDB 冷读合并，打开及事务各限 500 ms；存储慢/拒绝时回退实时网络，不能无限挂住启动。
  清除前写无身份信息的本机 tombstone，避免删除事务受阻时下次导航复活缓存；仅当前身份成功写入后移除此标记。
- 登录门只引入独立 primitives；工作台动态加载，设备详情和设置也按需加载。页面加载期间保留导航，
  失败可重试（重建 lazy promise，而非仅重置错误边界）。桌面共用页面也获得分包，需通过 Electron CI 验证。
  登录、连接中和错误页复用 192px `/favicon.png`（约 31 KB），不再下载 512px `/logo.png`（约 225 KB）。
- 已控制的 `/` 与 `/devices/:id` 导航直接返回本 revision 已验证的公共壳，不等待穿透链路；
  会话、设备正文仍由网络/绑定身份的 IndexedDB 提供。API、socket、RSC、Authorization、非 GET、query、
  跨域和其他未来服务端页面不由此路径接管。更新仍需用户激活新 worker，不静默混入新版本 HTML。
- 原子核心保留完整共享/异步 UI 及依赖媒体，不能为了缩小清单破坏离线详情/设置；排除独立设备路由、
  not-found bootstrap 和 Pages-router 构建清单（设备深链离线由根公共壳承接）。这些资源按当前 manifest 白名单按需缓存。
  安装阶段跨代复用声明过的内容哈希资源；根 HTML、公共图片、安装 manifest 与 build-ID 清单必须重新读取。
  revision/壳 meta、资源 HTTP 状态、重定向、JS/CSS MIME 校验失败则放弃候选，保留旧完整壳；保留前一代支持旧标签页。
- 基线 PR #76 的真实 CI 构建报告首页/设备页 First Load JS 均为 213 kB，原子缓存 28 个公共资源。
  本阶段 CI 会报告新 First Load JS、核心/按需资源数量与原始字节（HTML 除外）；这些不是实际 HTTP 压缩总量或公网加载秒数。
  新安装/无 worker/HTTP 非安全入口不能享受已缓存壳；没有部署本任务代码，真实公网对照仍待联合验收。

阶段 5 的实际 CI 结果（[run 39436749835](https://github.com/IGNGserver/guanlan-monitor/actions/runs/39436749835)）：
首页/设备页 First Load JS 均为 137 kB，相对 213 kB 基线减少约 36%；不是完整工作台总下载或加载秒数减少 36%。
PWA 核心 27 资源 / 1,463,844 原始字节（不含 HTML），按需 5 资源 / 233,492 原始字节；离线详情/设置及 Chromium/WebKit 回归通过。

## 阶段 6a 桌面原生读取

- 初始化优先恢复加密凭据内最近成功连接的 Hub 地址，缺失时读已有本机配置；Agent 状态探测独立后台完成。远端摘要不等待 Agent 启动、
  可选图表/日历、更新检查或缓存落盘；每项成功后逐步发布。Agent 不可用时仍可查看已配置 Hub，
  首次仅能通过 Agent 发现地址的场景在地址发现后补刷新，不合成本机伪设备。
- IPC 严格保留/校验 `include`、`networkMode`、`background`，旧调用省略 include 时保持完整读取。
  可选读取最多 2 路，省流/慢摘要自动模式 1 路；认证和摘要不排队。标准返回完整点，省流/受限自动目标 120 点。
  桌面自动模式只参考摘要请求平滑耗时，不使用不存在的浏览器 Network Information API，也不把它标成 RTT。
- 设备/范围/策略切换、隐藏、离线、退出和身份变化取消旧等待；Hub 请求 deadline 包含响应体，
  底层忽略 abort 也能结束等待。隐藏窗口 IPC 不发起读取。摘要/可选图表失败对自动网络轮询退避至最多 120 秒，
  受限模式至少 30 秒；手动/online 恢复立即，成功清计数。renderer 定时器可能仍发轻量 IPC，主进程负责实际网络频率。
- 401/403 清空私有内存/落盘缓存并隔离迟到结果。管理写操作不重新认证后自动重放；只有 GET 可合并登录后重试一次。
  显式身份切换等待期间暂停摘要/缓存恢复，连接修改不交错执行；切换失败清凭据，不让定时器悄悄登录回旧账号。
- 离线缓存 schema 2 绑定规范 Hub 地址和随机身份标识，TTL 24 小时、文件最大 4 MB；过大图表退回只缓存摘要。
  身份标识随凭据保存在 Electron safeStorage 加密载荷内，缓存本身无密钥、Cookie 或密钥 hash。
  不支持安全凭据持久化时身份仅本进程有效，跨启动宁可缓存 miss。旧无 scope 缓存不恢复。
  缓存视图强制只读，不含本机 Agent 配置或更新操作；清理与写入串行且有代次栅栏，旧 flush 不得复活退出前的内容。
- 本地用源码图的逻辑测试，不生成 dist；同一既有性能测试仍在 CI 对真实 dist 再跑（含包依赖断言）。
  Electron 视觉、三平台生产编译/打包由 PR CI 验证，真实代表设备冷启动数据仍未采集。

## 测量方法

### 未认证入口

在本地 scratch 或 CI 副本执行，报告不要写回 NAS 源码卷：

```sh
pnpm performance:baseline --samples 5 --vantage 'client/network; proxy/TUN route' \
  --out "$BUILD_SCRATCH_ROOT/guanlan-monitor/loading-baseline.json" \
  http://nas-host:38472 https://public-hub.example
```

工具仅允许无凭据、无 query 的 HTTP(S) origin；串行、有超时、最多 20 次采样。
只导出白名单状态、时延和公共响应头，不导出 Cookie、响应体、证书或 curl 原始错误。
非 200 和失败请求单独计数，不能用其快速失败美化百分位数。小样本百分位仅供排查。
工具无法自动识别透明代理或 TUN，必须记录测量视角；不要为了测量更改全局代理策略。

### Web / PWA / Electron renderer

浏览器 Performance 面板或本地 DevTools：

```js
performance.getEntriesByType('mark').filter(x => x.name.startsWith('guanlan:'))
```

- `shell-committed`：工作区 React effect 首次提交，**不是像素绘制完成或登录页显示**。
- `cache-committed`：首次提交缓存快照。
- `hub-summary-committed`：首次提交 Hub 快照，不保证 Agent 数据刚刚采集。
- `hub-charts-committed`：首次提交含图表的 Hub 快照。

标签在一次页面生命周期内只记录一次，无远程上报和设备 ID。
同时采集 Navigation/Resource Timing、FCP/LCP、请求数和压缩传输量；标签不代替浏览器绘制指标。
PWA 区分新安装、已受控启动、版本更新；无 HTTPS 的公网入口单列为不支持离线启动。

### Hub

`Server-Timing: hub;dur=...` 是收到请求至响应序列化后、发送前的服务端耗时。
不包含客户端 DNS/TLS、隧道传输、响应体下载或渲染。
Next/入口代理是否保留此头须线上验证；不能用 TTFB 直接替代数据库时间。
后续服务端阶段补充热点查询分项与扫描行数。

### Android / Electron 主进程

Android 本地 `adb logcat -s GuanlanLoading`：固定里程碑和自 Activity 实例创建后的单调时钟耗时。
Activity 首次提交缓存/Hub 数据时调用 `reportFullyDrawn`；冷启动仍以 Macrobenchmark/Perfetto
系统启动指标为准，不能把 Activity 内时间冒充进程冷启动时间。
Electron 既有本地诊断事件新增 `processElapsedMs`，与 renderer User Timing 分开记录。
日志不包含密钥、设备 ID、会话或遥测正文。

## 最终测试矩阵与初始预算

### 阶段 6b Android 实现边界

- 连接地址、访问密钥、随机缓存身份和网络模式放进现有 EncryptedSharedPreferences 的**单个 JSON 记录**，
  commit 一次发布；首次从旧 DataStore 地址+加密密钥迁移，空记录作为退出标记，不因重启再迁回旧设置。
  UUID 不由密钥派生；相同 Hub/密钥切模式不换身份，换 Hub/密钥生成新身份。
- 先确定设置再并行读 scope 缓存与联网登录；有效缓存可先展示只读界面，迟到缓存不得覆盖 live。
  schema 2 缓存匹配 Hub/身份，24 小时 TTL、4 MB、最多 8 个设备的最近已读图表；旧无 scope 文件不恢复。
  写入捕获不可变状态副本、scope 和 epoch；清理先失效再串行删除，旧写任务不能在退出后复活。
- 冷启动/身份切换登录单飞；前台恢复复用有效会话。并发 401 只针对观察到的 session version 合并续期，
  GET 最多重试一次；所有管理写操作不重放，OkHttp 的连接失败自动重试也关闭。
  OkHttp callTimeout 15 秒覆盖 headers/body，整项操作含认证/一次 GET 重试可能超过 15 秒。
- 摘要先提交，总览/详情/流量按当前页面补齐；设置页不读图，关注规则只在关注页读取全精度序列。
  关注页用固定 1–2 个 worker，不为全设备建立无界协程；切页/后台取消等待，旧身份响应不清新身份。
  CancellationException 显式传播，不再被异步 runCatching 伪装成普通失败。
- 自动/标准/省流模式可在设置选择。自动参考平滑摘要请求耗时，不标成 RTT；受限请求目标 120 点，
  至少 30 秒轮询，失败退避至 120 秒，手动/前台恢复不等退避。
  采样元数据保留到 DTO 和页面提示，展示点均值不冒充完整序列均值；关注规则不使用采样曲线，累计流量仍不抽稀。
- 新增 JVM 协调器/缓存文件测试，以及 Robolectric 的实际 MainViewModel 夹具：慢总览不挡摘要、
  前台不重复登录、旧身份迟到登录隔离、关注页省流串行和切页取消。尚待 PR CI 编译/执行，
  本机无 Android SDK，没有声称已跑过原生测试或获得真实冷启动分位数。

- 参考弱网：下行 1 Mbps、上行 256 Kbps、RTT 300 ms；另外测试超时、断网与恢复。
- 路径：内网、VPS、Cloudflare；记录运营商、代理/TUN、客户端及服务端版本。
- 场景：首次访问、重复启动、PWA 更新、安卓进程冷启动、Electron 冷启动、前台恢复。
- 设备规模：小/中/大固定夹具；真实设备测试标注实际规模。
- 目标：有效缓存可见 P75 ≤ 1 s；网页首次可操作 P75 ≤ 6 s；有效会话摘要 P75 ≤ 3 s。
- 更新与日历延迟 30 s 不得阻塞摘要；隐藏页无非必要轮询；旧响应不可跨设备/身份覆盖。
- 核心验收场景至少 20 次独立重复，报告失败率、样本量与 P50/P75；不承诺小样本 P95。
- 对比请求与字节预算，争取弱网典型场景下降 50%，保持缺失值、峰值和流量总计语义。
- CI 夹具结果与真实国内线路结果分别记录；未取得真实端点/设备证据时保留“待验收”。

## 安全与回退

公共壳可以边缘缓存，认证、RSC、Socket 与私有遥测不可公共缓存。
缓存绑定 Hub/身份/设备/时间窗口，有 TTL/容量上限；退出、401/403 和身份切换不得恢复旧缓存。
离线管理操作不排队重放。新接口向后兼容，省流、增量和 PWA 缓存策略独立保留回退路径。
