# Device State Console v0.2.0

## Highlights

- Windows GUI updates now open directly to the installation confirmation page.
- The installer closes the running Guanlan application and local backend before replacing files.
- Component probing runs automatically when Guanlan starts and remains available from Run Control for manual refreshes.
- CPU, disk, network, and GPU instance selection is integrated into the corresponding local status cards.
- The redundant standalone instance-records panel has been removed.
- Windows GUI setup, update, portable, CLI, Linux CLI, and Android packages are included in this release.
